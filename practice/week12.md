# 코드 실행 후기

## 가장 흥미로웠던 코드
오늘 실행해본 코드 중에서는 **cellular_cave 코드**가 가장 흥미로웠다.  
동굴 형태가 자동으로 생성되는 과정이 신기했고, 간단한 규칙만으로도 자연스러운 지형이 만들어지는 점이 인상적이었다.

## 파라미터 변화에 따른 결과

- **FILL_PROB**  
  값이 달라지면 동굴의 크기와 밀도가 달라졌다.  
  값이 높을수록 벽이 많아지고, 낮을수록 빈 공간이 많아지는 것을 확인할 수 있었다.

- **ITERATIONS**  
  반복 횟수가 달라지면서 동굴이 다듬어지는 정도가 달라졌다.  
  예를 들어 5번 반복했을 때보다 10번 반복했을 때 더 부드럽고 자연스러운 형태의 동굴이 생성되었다.

## 프로시저럴 생성 활용 가능성

기말 프로젝트에서 프로시저럴 생성을 활용할 수 있을지에 대해서는 아직 확신이 없다.  
하지만 자동으로 맵이나 구조를 생성할 수 있다는 점에서 게임 개발에 활용 가능성이 있을 것 같다는 생각이 들었다.
