# Abyss Snake 개발 대화 요약

## 1. 스네이크 캐릭터 및 애니메이션 제작 요청

사용자는 pygame 기반 스네이크 게임에 사용할 캐릭터 이미지를 요청했다.
단일 이미지가 아닌 게임에서 방향과 상태에 따라 사용할 수 있도록 머리, 몸통, 꼬리, 애니메이션 프레임으로 나누어 제작하도록 요청했다.

이에 따라 분리형 구조의 스네이크 이미지와 사과를 먹을 때 재생되는 애니메이션 프레임을 제작하여 제공했다.

---

## 2. 코드에 맞는 이미지 구조로 재요청

사용자는 pygame 코드에서 바로 사용할 수 있도록 이미지 이름과 구조를 코드 기준에 맞게 다시 정리해달라고 요청했다.

이에 따라 코드에서 불러오는 구조에 맞춰 이미지 파일 구성을 수정하고, 방향별 이미지와 몸통 연결 이미지가 자동으로 선택되도록 설계했다.

---

## 3. 포탈 애니메이션 추가 요청

사용자는 포탈을 단일 이미지가 아니라 애니메이션으로 구현하고 싶다고 요청했다.

이에 따라 포탈을 여러 프레임 이미지로 제작하고, 시간 기반으로 프레임이 변경되도록 pygame 코드에 애니메이션 로직을 추가했다.

---

## 4. 상대경로 기반 코드 수정 요청

사용자는 절대경로가 아닌 상대경로 방식으로 이미지와 사운드를 불러오도록 수정 요청을 했다.

이에 따라 실행 중인 파이썬 파일 위치를 기준으로 에셋 폴더를 탐색하도록 코드 구조를 변경했다.
또한 스네이크 이미지, 포탈 이미지, 사운드 파일을 각각 별도의 폴더에서 로드하도록 분리했다.

---

## 5. 실제 폴더 구조 반영 요청

사용자가 실제 폴더 구조를 이미지로 제공했고, 해당 구조에 맞도록 다시 상대경로를 수정했다.

이 과정에서 실행 파일 기준으로
스네이크 이미지 폴더
포탈 애니메이션 폴더
사운드 폴더
를 각각 찾도록 코드가 재구성되었다.

---

## 6. 이미지 로드 실패 문제 발생

사용자는 게임 실행 시 이미지가 로드되지 않는 문제를 보고했다.

원인 분석 결과

* 실행 중인 파이썬 파일 위치와
* 이미지가 저장된 폴더 위치가 서로 달랐다

즉 상대경로 기준점이 일치하지 않아 이미지 로드가 실패한 상황이었다.

이에 따라 실행 경로 출력, 이미지 탐색 경로 출력 기능을 추가하여 실제 참조 위치를 확인하도록 수정했다.
