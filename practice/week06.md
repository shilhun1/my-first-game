## 사용한 AI 프롬프트 (요약)
1. Pygame `FileNotFoundError` 원인 분석 및 파일 경로 수정 요청
2. 기획서(상태 머신, 포탈, 시야 제한, 사과 스폰) 기반 게임 기본 코드 프레임워크 작성 요청
3. 실제 이미지 에셋 파일명 동기화 및 BGM 무한 반복 재생 기능 추가 요청
4. 에디터 환경(`__file__` NameError) 동적 경로 예외 처리 로직 추가 요청
5. HUD 영역 사과 스폰 제한, 암흑 효과 투명도 상향, 배경 격자(Grid) 시각화 요청
6. 뱀 이동 끊김(Stuttering) 현상 해결 및 사과 먹는 효과음 지정 요청
7. `PINK` 변수명 참조 오류 수정 요청
8. 맵 축소 시 즉사 방지를 위한 5초 예고 타이머 도입 및 목숨 초기화 버그 1차 수정 요청
9. 뱀 체절 방향(직선, 코너, 꼬리)에 따른 14종 에셋 지능형 렌더링 로직 도입 요청
10. 맵 이탈 사과 스폰 및 목숨 차감 중복 버그 2차 수정 요청
11. `pygame.transform.rotate`를 활용한 사과 360도 회전 애니메이션 로직 추가 요청
12. 프레임 폴더(`apple_red_anim` 등) 다중 이미지를 활용한 프레임 전환 애니메이션 구현 요청
13. `base64`와 `io.BytesIO`를 활용한 로컬 사운드 파일 코드 임베딩 요청
14. 사과 시각적 크기 1.8배 확대 및 단일 이미지 회전 로직으로 애니메이션 롤백(Rollback) 요청

## AI 답변에서 도움이 된 것
- 에러(`FileNotFoundError`, `NameError`)의 명확한 원인 파악 및 동적 경로 할당(`os.getcwd()`)을 통한 해결.
- 입력 이벤트(`KEYDOWN`)와 이동 연산(`update`)을 분리하여 키보드 입력 지연에 따른 뱀의 이동 끊김 현상을 부드럽게 해결한 구조적 분리 로직.
- 뱀의 각 체절(Segment)이 이전 체절과 다음 체절의 상대 좌표(Vector)를 계산하여, 적절한 코너(L자) 및 꼬리 에셋을 스스로 판단해 렌더링하는 알고리즘.
- 맵 축소에 따른 불합리한 즉사를 방지하기 위해 경고 타이머 변수를 도입하고, 축소 후 안전 구역으로 오브젝트를 관리하는 로직.

## AI 답변을 수정하거나 버린 것
- 프레임 시퀀스 폴더를 활용한 애니메이션 로직은 코드에 구현되었으나, 최종적으로 성능과 편의성을 위해 단일 이미지 수학적 회전 로직으로 수정(폐기)됨.
- 최초 제공된 사과 획득 사운드(`EatSound_CC0...ogg`)는 사용자 로컬 에셋인 `Untitled 1.wav` 파일로 대체됨.
- 사운드 파일 Base64 임베딩은 로컬 파일 접근 권한 문제로 직접 작성되지 않고, 변환용 별도 스크립트를 제공받아 사용자가 직접 코드를 삽입하는 방식으로 수정됨.

## 적용 결과
- **잘 된 것:** 기획한 모든 요소(암흑, 다이내믹 맵, 포탈, 방향별 에셋, 사운드 등)가 치명적인 버그나 성능 저하 없이 유기적으로 맞물려 작동하는 최종 코드가 완성됨.
- **어려웠던 것:** 상태 머신 내에서 이벤트와 타이머(얼음 사과 쿨다운, 맵 축소 예고)를 엉킴 없이 관리하는 것과, 맵 크기가 동적으로 변할 때 오브젝트(사과, 포탈)의 좌표 유효성을 검사하는 논리 연산.
- **다음에 시도할 것:** 매 프레임마다 발생하는 이미지 회전 및 스케일링 연산 부하를 줄이기 위해, 게임 초기화 단계에서 미리 연산된 이미지를 캐싱(Caching)하는 성능 최적화 진행. 또한, Base64 임베딩 대신 PyInstaller를 활용한 실행 파일(.exe) 패키징 시도.
